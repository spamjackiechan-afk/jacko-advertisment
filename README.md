# On Call Advertisment

Static website for On Call Advertisment — affordable photo transformations and advertising visuals, created remotely from customers' existing photos.

- `dist/` is the complete site (no build step). It is published as the website root.
- `.github/workflows/pages.yml` deploys `dist/` to GitHub Pages on every push to `main`.
